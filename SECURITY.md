# Security Policy

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately through GitHub: go to the **Security** tab of this repository and click **Report a vulnerability**. You should receive a response within 7 days. If the issue is confirmed, a fix will be released and you will be credited (unless you prefer otherwise).
